🚀 O Que é Isso?

O hub-agentes-ia é a ferramenta perfeita para você que quer seu próprio agente de inteligência artificial treinado exatamente no seu método de trabalho. Imagine um chatbot que sabe lidar com seus clientes, responde perguntas sobre seu negócio, e ainda vende automaticamente por você — tudo isso montado sem escrever uma única linha de código.

Com ele, você cria uma central completa com login, painel administrativo e sistema de venda automática. É ideal para consultores, pequenos negócios, criadores de conteúdo e empreendedores que querem oferecer respostas inteligentes e personalizadas, 24 horas por dia.

Pense nele como um "funcionário digital" que já vem treinado com seu conhecimento, pronto para atender e converter. E o melhor? Tudo construído com a ajuda da própria IA, seguindo passos simples.

✨ Principais Recursos

💼 Painel Admin Completo

Controle total de usuários, agentes, vendas e relatórios em um painel visual e fácil de usar. Gerencie tudo sem sujar as mãos com código.

🛒 Venda Automática Integrada

Sistema de checkout integrado que trabalha por você. O agente conduz a conversa, oferece produtos e processa pagamentos automaticamente.

🔐 Login Seguro Supabase

Autenticação robusta de usuários com o Supabase. Seus clientes e parceiros terão acesso protegido às áreas que você definiu.

🏆 Treinamento Personalizado (RAG)

Use sua própria documentação, PDFs, planilhas ou artigos. O agente usa a tecnologia RAG para buscar respostas exatas no seu método.

Além disso, o hub vem com suporte total ao português, funciona como PWA (instalável no celular), usa ChatGPT da OpenAI e se conecta perfeitamente com ferramentas modernas como Next.js, Tailwind e bancos de dados vetoriais.

📥 Download e Instalação (Windows)

Siga os passos abaixo para ter o hub-agentes-ia rodando no seu computador Windows. São simples e diretos — sem precisar de conhecimentos técnicos.

PASSO 1 — Baixar o arquivo

Clique no botão verde abaixo para visitar a página do projeto no GitHub. Nessa página, você vai encontrar todos os arquivos necessários para o download.

⬇️ Visite o Link

📝 Sobre a página: Ao clicar, você será levado à página principal do projeto. Lá, no botão verde "Code", você pode escolher baixar como arquivo ZIP ou clonar com Git. Para a maioria dos usuários, baixar o ZIP é a opção mais fácil.

PASSO 2 — Extrair e instalar

Depois de baixar o arquivo .zip (ou master.zip), encontre-o na sua pasta de Downloads. Clique com o botão direito nele e escolha "Extrair tudo..." para abrir a pasta do projeto.

Dentro da pasta extraída, você verá um arquivo chamado README.md. Abra esse arquivo! Ele contém instruções completas de configuração. Em seguida, abra o arquivo .env.example e renomeie para .env.local. Preencha os campos com as suas chaves da OpenAI e do Supabase (o guia no README explica isso melhor).

PASSO 3 — Rodar pela primeira vez

Abra o terminal do seu computador (procure por "Prompt de Comando" ou "Terminal"). Navegue até a pasta do projeto usando o comando cd. Depois, digite npm install e pressione Enter. Isso instala todas as dependências. Aguarde finalizar.

Por fim, digite npm run dev e pressione Enter. O sistema vai iniciar e mostrar um link (ex: http://localhost:3000). Abra esse link no seu navegador e pronto — seu agente estará funcionando!

❓ Dúvidas Comuns

🤔 "Vou precisar programar?"
Não. Este template foi feito para ser montado seguindo instruções simples. A própria IA ajuda a configurar. Você apenas ajusta textos e informações do seu negócio.

💡 "Posso vender usando este hub?"
Sim! O sistema já vem com módulo de venda automática, e você pode definir preços, produtos e formas de pagamento. Perfeito para criar seu próprio SaaS ou consultoria automatizada.

📈 "Funciona para minha área?"
Se sua atividade envolve responder perguntas, atender clientes, ou ensinar um método, sim. O agente é treinado com seus materiais, então se adapta a qualquer nicho.

🔒 "Meus dados estão seguros?"
Absolutamente. O Supabase garante autenticação segura, e o banco de dados usa criptografia. Seus dados e os de seus clientes ficam protegidos.
